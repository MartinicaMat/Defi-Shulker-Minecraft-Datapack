# Défi Shulker

Un défi de survie où l'immobilisme est interdit ! Ce datapack vous force à adopter un style de vie **100% nomade** en vous obligeant à explorer le monde en continu.

---

## Fonctionnement
Dès votre apparition, vous recevez **5 Shulker Boxes** de couleurs différentes. Ce sont vos seuls coffres pour toute l'aventure ! Rangez-y vos ressources, car vous allez devoir les transporter partout.

---

## Le Chrono
Un chronomètre invisible de **5 jours Minecraft** (120 000 ticks) se lance. 
* Un message s'affiche dans le chat lorsqu'il reste **1 jour**.
* Un grand titre claque à l'écran à **10 secondes** de la fin.

---

## Les Malus
Si le chrono tombe à **0** :
* Un message d'alerte rouge s'affiche.
* Vous recevez les effets **Faim III** et **Lenteur II**.
* Les malus restent actifs tant que vous ne changez pas de zone.

---

## Comment enlever les effets ?
Pour stopper les malus et remettre le chrono à 5 jours, vous devez **déménager**. 
Dès que vous parcourez plus de **150 blocs** loin de votre campement, le système valide votre exploration, affiche un message vert et réinitialise le temps !
